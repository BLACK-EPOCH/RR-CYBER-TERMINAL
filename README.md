📦 Installation

pkg update -y
pkg install git bash coreutils -y
git clone https://github.com/BLACK-EPOCH/RR-CYBER-TERMINAL.git
cd RR-CYBER-TERMINAL
bash install.sh
rrcyber

🎮 Commands

Command| Description
"rrcyber"| Launch terminal
"rrname"| Change username
"channel"| Open Telegram
"exit"| Exit terminal
